# CLAUDE.md

## Repository rules

- This is the only repository to write to for this game.
- These sibling repositories are read-only references, set in the same world. Reuse their landscapes, assets and code when useful, but never commit to them:
  - `chriskizer91-ops/20-min`
  - `chriskizer91-ops/airship-game-in-aethermoor-`
  - `chriskizer91-ops/envoi-on-the-longest-night`
  - `chriskizer91-ops/follow-me-down-witch-way`
- When copying assets or code from a sibling repo, note the source repo and path in the commit message.
- Moon Faire's own docs and lore outrank anything in a sibling repo. Don't bring a sibling's lore, tone rules or mechanics over them.

## Project

- *Moon Faire*: four performers on a festival airship touring Aethermoor, on Chris's world Thareia. Each is a witch with a hidden weapon and one phase of the moon. The Ranger is the Full Moon, the Herbal Witch the Waxing Moon, the Fox the Waning Crescent and the Jester the New Moon.
- Read `docs/START-HERE-sprite-animation-method.md` and `assets/HANDOFF.md` before touching any animation.
- `assets/` is the game asset export (`manifest.json`, `hd/`, `pixel/`, `design/`). It's generated by the art pipeline, so replace it wholesale on a new export and never hand-edit it.
- `art-pipeline/` holds the cut frames (`frames/` with `meta.json`), the scripts, the original sheets and the current smoothing pack. The scripts still carry paths from the old art workspace (`/home/claude/...`).
- Read clips from `manifest.json`. Draw every frame on its anchor, and fire gameplay on `release_frame`. Don't mirror spells, because the costumes are asymmetric.
- Names for the four, the moon and the planets are still open, so keep text in data files.
- Chris tries things on his phone. Every step should end with something he can open there. Write anything Chris reads in plain words.
