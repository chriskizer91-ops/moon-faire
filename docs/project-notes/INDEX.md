# Project notes: index

Written November 18, 2026. This folder is a copy of everything in the knowledge of the claude.ai project **Flip Book Art**, saved into the moon-faire repo before Moon Faire and the new Envoi are merged into one game.

## What is here

- **147 project documents**, at the same paths and names they have in the project: 139 in `claude/`, 1 in `claude/light-levels/`, 5 in `lore/` and 2 in `lore/sim/`. They are unchanged, apart from five marked spots in four of them where a personal detail was left out (see "Left out on purpose" below).
- `INDEX.md`: this file.
- `decisions.md`: Chris's stated decisions, newest first, written from the project's memory.
- `artifacts/`: the three pages that exist only as artifacts (four files), with a `README.md` giving each one's link.

## Where to start

- `lore/README.md` and `lore/discussion-notes.md`: the lore as it stands. Chris's own words outrank everything else.
- `lore/combat-balance.md`: the combat system Chris approved.
- `claude/TASK-BOARD-moon-faire-game.md`: everything left to make the game, and who did what.
- `claude/HANDOFF-starter-world-to-the-open-world.md`: how the game's pieces fit together.
- `claude/HOW-TO-3d-witch-models.md`, `claude/HOW-TO-3d-witch-faces.md`, `claude/HOW-TO-3d-light-levels.md`, `claude/HOW-TO-flipbook-look.md` and `claude/HOW-TO-moon-faire-fair-folk-npcs.md`: the methods.
- `decisions.md`: what Chris has decided, with the older choices marked as replaced.

## How to read the tables

- **Date** is the date the project gives for each document, in UTC. Chris's evenings fall on the next UTC day, and several notes were updated after that date. The date written inside a note is the one to trust.
- **Pages it names** lists every artifact link in the document, with whether the repo can rebuild that page:
  - **yes**: the script that builds the page (or the page's own source) is in the repo.
  - **built copy kept**: no build script was found, but the finished page is in the repo.
  - **no, saved in `artifacts/`**: the page exists only as an artifact, so its HTML is saved in this folder.
- Most build scripts are on the work branches, not the default branch. The table of pages below says which branch.
- "Can rebuild" was checked by finding the script or page in the repo's branches. The builds were not run for this index. Some need pictures or tools that are not in the repo; the notes for each page say what.

## How the copies were checked

The project hands each document over as text, so every copy was written out from that text. Where the repo already held the same document, the copy was compared with it:

- **7 copies are the same, byte for byte, as a copy already in the repo**: `lore/sim/blob-battle-engine.js`, `claude/grey-hat-3d-reference-prompts.md`, `claude/ranger-3d-reference-prompts.md`, `claude/jester-game-model-reference-prompts.md`, `claude/HOW-TO-3d-witch-faces.md`, `claude/three-witches-animation-plan.md` and `claude/jester-animation-decisions.md`.
- **2 more are the same as the repo's copy apart from the marked spots where a personal detail was left out**: `claude/START-HERE-sprite-animation-method.md` and `claude/HANDOFF-game-build.md`.
- **2 more match the repo's single combined file**: `claude/io-3d-reference-prompts.md` and `claude/io-3d-reference-prompts-rounds-2-4.md` (the opening, the ending and all 62 prompt blocks of rounds 2 to 4).
- **3 differ from the repo's copy only where the project's version is a different version**: `claude/HOW-TO-3d-witch-models.md` (three later lines in the project), `claude/night-of-no-moon-game.md` (one sentence worded differently) and `claude/light-levels/lodpage.js` (the repo's copy has later additions). The project's wording was kept.
- **Code inside the notes**: the scripts printed in full in the light-levels, map editor, pilot camera and Flipbook-look notes were compared with the script files on branch `claude/moon-faire-light-levels`: 12 are the same, and a thirteenth, `patch_pilot_flipbook.py`, differs only by a newer three-line change in the repo. The 22 round 3 prompts in the Fox's prompt note match the repo's `models/fox-3d/references/round3/PROMPTS.txt`.
- `lore/sim/moonfaire_sim.py` has no copy in the repo. It was run and plays sample fights without error.
- **Everything else was written out from the project's text with no second copy to compare against.** Each was written with care, but if a line in one of those notes ever looks wrong, the project's own document is the original.
